# Run Tracker

แอปบันทึกการวิ่งภาษาไทย สำหรับดูรายการ เพิ่ม แก้ไข และลบข้อมูลการวิ่ง พร้อมรูปถ่ายจากกล้องได้ (ไม่บังคับ)

ไม่ใช่แอปติดตาม GPS แบบเรียลไทม์ และไม่มีหน้าล็อกอิน

## ฟีเจอร์

- หน้าต้อนรับ แล้วไปหน้ารายการวิ่ง
- ดูรายการวิ่งทั้งหมด
- เพิ่มรายการวิ่ง และถ่ายรูปประกอบได้
- แก้ไขหรือลบรายการวิ่ง

## สแต็ก

- Flutter
- Riverpod
- go_router
- Supabase

ข้อมูลเก็บในตาราง `run_tb` และรูปเก็บในบัคเก็ต `run_bk` รายละเอียดสคีมาและนโยบายอยู่ที่ `supabase/schema.sql`

## วิธีรัน

คัดลอก `.env.example` เป็น `.env` แล้วใส่ค่าโปรเจกต์ Supabase ของคุณ

```bash
flutter pub get
flutter run --dart-define-from-file=.env
```

ถ้ายังไม่ได้ตั้งค่า Supabase แอปจะเปิดด้วยข้อมูลตัวอย่างในเครื่อง
